# 0003: B2の検証用プロビジョニング情報

日本語 | [English](../en/decisions/0003-ftpm-provisioning-data.md)

状態：ユーザーの判断待ち。B2そのものは承認済みであり、PTAの組み込みは進める。

NVIDIAのhelper PTA全体は、起動状態通知に加えてFirmware ID鍵・証明書、fTPM seed、
SN、EPS seed、EK証明書またはSID証明書とEK CSRを利用する。
鍵・証明書を使った実行検証には、次のデータの選択が必要。

| 候補 | 利点 | 制約 |
| --- | --- | --- |
| QEMU専用テストCAと仮想デバイスの鍵・証明書を生成（推奨） | 実際の署名・検証や証明書APIを再現可能な入力で試験できる | NVIDIAや実機の製造証明書としての信頼はない。テスト用と明記する |
| ユーザー手持ちの鍵・証明書・プロビジョニング情報を使用 | 手持ちの証明書チェーンや既存データとの整合性を試験できる | 入力データの準備が必要。仮想デバイスのSN・seed・鍵との整合性確認が必要 |

判断前にはテストCAやFirmware ID秘密鍵を生成しない。
PTA本体のビルド、仮想プラットフォームへの接続、受け渡しデータの形式・境界検査は独立して進める。
