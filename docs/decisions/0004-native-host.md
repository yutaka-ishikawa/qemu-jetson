# 0004: Dockerを使わないビルド・実行

日本語 | [English](../en/decisions/0004-native-host.md)

状態：ユーザー承認済み。ユーザーがDockerを使わない構成への変更を明示的に指定した。

| 候補 | 利点 | 制約 |
| --- | --- | --- |
| 従来のDocker構成 | ツールのバージョンをイメージで揃えられる | Dockerの導入・デーモンへの権限・イメージ用容量が必要 |
| ホスト直接実行（採用） | Dockerやbuildxが不要。ホストからビルド・起動できる | ホストに依存ツールを導入する。rootfsの所有者情報を保つ組み立ては管理者権限が必要 |

QEMUは通常ユーザーでビルドし、既定では`work/qemu-build/`へ出力する。システムへのmake installは行わない。
依存ツール導入はユーザーが明示的に実行する別スクリプトとし、ビルド中の自動導入を避ける。
Ubuntu Base＋PRootの構成とNVIDIA PTA/TAは維持し、ビルド・起動・ディスク処理のDocker呼び出しを除く。
既存の鍵・証明書・NVディスクは保持する。
詳細・導入手順・検証範囲は[ホスト環境](../native-host.md)を参照。
