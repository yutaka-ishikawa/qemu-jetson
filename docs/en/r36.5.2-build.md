## Procedure

Actual working directory structure; distributions were stored outside the repository:

```text
/workspace/work/nvidia-r36.5.2/
├── optee/                     # Extracted nested OP-TEE archive
├── toolchain/aarch64--glibc--stable-2022.08-1/
├── Linux_for_Tegra/bootloader/standalonemm_optee_t234.bin
├── host-tools/usr/bin/dtc      # Extracted with dpkg-deb -x
└── venv/
```

Create the venv using `python3 -m venv` and install the packages listed in the shared requirements file.
A separate host-tools directory is unnecessary when DTC can be installed through normal package management.

Executed build commands:

```bash
export CROSS_COMPILE_AARCH64_PATH=/workspace/work/nvidia-r36.5.2/toolchain/aarch64--glibc--stable-2022.08-1
export UEFI_STMM_PATH=/workspace/work/nvidia-r36.5.2/Linux_for_Tegra/bootloader/standalonemm_optee_t234.bin
export PYTHON3_PATH=/workspace/work/nvidia-r36.5.2/venv/bin/python3
export PATH=/workspace/work/nvidia-r36.5.2/host-tools/usr/bin:/workspace/work/nvidia-r36.5.2/venv/bin:$PATH
cd /workspace/work/nvidia-r36.5.2/optee
./optee_src_build.sh -p t234 -t > ../build.log 2>&1
```

The official script removes the target build/install directories before rebuilding.
Preserve any artifacts you need elsewhere before rerunning it.

## Results and verification

The official script exited with code 0 and printed `optee sources compiled successfully.`.
Comparing all 4,214 regular files from the source archive against the extracted files found zero changes and zero missing files.
Newly generated build/install files were outside that comparison.

`file` identified OP-TEE `core/tee.elf` and the fTPM TA ELF as AArch64.
The generated conf.mk includes:

```make
CFG_CORE_TPM_EVENT_LOG=y
CFG_EARLY_TA=y
CFG_JETSON_FTPM_HELPER_PTA=y
CFG_WITH_STMM_SP=y
```
